# 🎒 Loadouts

A loadout is a snap shot of your current enabled characters, hotbars and windows.

In addition it caches the autolaunch settings. This is useful if you use boxcar for different games etc. 

Loadouts do **NOT** cache the UI settings.

---

## ⚙️ Properties

- **Name**  
  - A unique identifier for the loadout.


## 🛠️ Actions

- **Apply**  
  - This will apply the snap shot to the apps current state.

- **Update**  
  - This will retake the snap shot of the current app state.

- **Delete**  
  - This will remove the loadout from the list.
