# 🌎 Global UI

- **Window Background**
	- Changes the background color of all overlay windows.
	
- **Window Border**
	- Changes the border color of all overlay windows.

- **Character Background**
	- The background color of character buttons when the character is considered **inactive**

- **Character Text Color**
	- The text color of character buttons when the character is considered **inactive**

- **Actiive Character Background**
	- The background color of character buttons when the character is considered **active**

- **Active Character Text Color**
	- The text color of character buttons when the character is considered **active**
	
- **Window Border Thickness**
	- Changes the border thickness of all overlay windows.
	
- **Window Active Opacity**
	- The opacity of the overlay window when a mouse is hovered over the window.
	
- **Window Inactive Opacity**
	- The opacity of the overlay window when a mouse is NOT currently hovering.
	- This cannot be set to 0 due to an existing issue.
	
- **Window Margin**
	- The Margin applied to the windows child container, providing more space around the edge.
	
- **Character Button Width**
	- The fixed width applied to all character buttons, typically adjusted based on character names.
	
- **Button Height**
	- The fixed height applied to all buttons.
	
- **Button Corner Radius**
	- The corner radius to apply to all buttons.
	
- **Use Fixed Button Width**
	- An option to use a fixed width vs dynamic width based on title content for non character buttons.
	
- **Fixed Button Width**
	- If opted into the **Use Fixed Button Width** this is the width that will be applied to **non character** buttons. 
	
- **Font Size**
	- The font size applied to all buttons.
